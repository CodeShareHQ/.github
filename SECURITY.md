Security Policy

CodeShare takes software security seriously.

We appreciate responsible security researchers and developers who help keep our projects safe.

Reporting a Vulnerability

If you discover a security vulnerability in one of our projects:

1. Do not publicly disclose the vulnerability before it has been addressed.
2. Contact the repository maintainer through an available private reporting channel.
3. Include a clear description of the issue.
4. Provide steps to reproduce the issue when safe and appropriate.

Security Guidelines

- Never commit API keys, passwords, or access tokens.
- Keep dependencies updated.
- Validate untrusted input.
- Follow secure coding practices.
- Review third-party dependencies before using them.

Scope

Each repository may have its own security policy and supported versions.

Please check the individual project's documentation.

Thank you for helping keep CodeShareHQ secure.
